# Roadmap

`docs/roadmap/`は、現在有効な設計と将来像の差分だけを記録します。現在の仕様は[設計書](../design/README.md)が正本であり、roadmapは正本ではありません。

各項目には、現在できること、まだ接続されていないこと、完了と判断する条件だけを書きます。現在の設計全文、変更履歴、調査の経緯は重複して記載しません。

roadmapの項目を実装した場合は、必要な契約を`docs/design/`へ反映し、その項目をroadmapから削除します。
