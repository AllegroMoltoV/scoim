# 参照曲を基準にした新規生成

参照曲は、既存の固定校正曲を変形するためではなく、新しい構成、楽譜、演奏を作るための特徴目標として使う。曲名や生の音符列をLLMへ渡さず、検証済みの観測値を匿名の生成目標へ変換する。参照への近さ、コピーでないこと、音楽として破綻しないことを別々に判定する。

## 要求の解決

| 入力 | 解決方法 |
|---|---|
| 参照曲を指定 | 指定曲の検証済み参照記録を使う |
| 参照曲を省略 | 現在の既定medoidである`SonataForHouseMoving.mid`を使う |
| 制御値を省略 | 選択した参照曲自身の正規化値を使う |
| 制御値を指定 | コーパスmin/maxの共通座標で、その項目だけを上書きする |
| 制御値を`0`と指定 | コーパスmin/maxの算術中点を使う |

省略と明示的な`0`は別の要求である。参照曲の詳細特徴と、利用者が上書きした`あかるさ`、`高さ`、`発音頻度`を混ぜずに保存する。制御の詳しい意味は[生成制御](generation-control-interface.md)に従う。

## 入力の検証

参照基準と制御基準は、records、summary、manifestを一組として読む。処理前に完了状態、方式版、件数、出力ファイルのSHA-256、基準どうしの依存hashを検査する。指定曲が両方の記録に存在し、観測値が有限で、必要な近傍がすべて存在することを要求する。

欠損、不正な次元、非有限値、版またはhashの不一致は生成前の失敗とする。別の参照、中央値、端点へ黙って置き換えない。

## 参照特徴

各特徴は、指定曲の値である`anchor`、近傍の中心、近傍の広がりを持つ。分布値は合計1へ正規化し、成分ごとのmin/maxを組み合わせて実在しない分布を作らない。

参照特徴は一つの総合lossへ合算せず、主な生成担当へ分ける。

| 担当 | 主な特徴 |
|---|---|
| 楽譜 | 発音群サイズ、音域、音程進行、旋律方向、縦音程 |
| 演奏 | velocity分布、ペダル保持、ペダル変更 |
| 楽譜と演奏の両方 | 時間加重ポリフォニー、発音間隔、音価、休止 |

最終的な達成値は`RenderedPerformance`とSMFから再測定する。楽譜と演奏の両方に依存する特徴を、片方だけの責任にしない。

## 観測値と意味目標

互換性と後方比較に使う低水準観測値と、生成時に実行できる少数の意味目標を分ける。LLMへ長い特徴配列だけを渡して作曲操作を推測させず、Pythonが観測値を担当段階、平易な意味、具体的な操作、到達可能性へ決定的に変換する。

現在使う主な意味目標は次のとおりである。

- `attack_frequency`: 30 ms発音群に基づく全曲の発音回数。
- `attack_texture`: 発音群ごとの単音、2音、3音、4音以上の配分。
- `key_held_texture`: ペダルを除き、鍵盤を保持している音数の時間配分。
- `foreground_accompaniment_coordination`: 前景と伴奏が句頭、和声転換、強調点、終止で合流しつつ独立運動を残すこと。
- `coordination_preservation`: 厚い発音を保つ場所で、演奏上のロールによって薄くし過ぎないこと。
- `register_envelope`: 全曲の音域幅と旋律を含む安全な音域。
- `velocity_shape`: 区分と声部の役割を保った強弱分布。

意味目標を生成段階へ渡しただけでは達成としない。生成前と配達直後は`unassessed`とし、機械検査または人間の試聴後にだけ`achieved`または`unmet`へ変える。現在の下位表現で表せない場合は、入力hash、表現の版、理由を伴う`unrepresentable`にする。

## 創作上の指示

参照SMFの観測値だけでは、曲全体の山場、和声上の対比、旋律の役割、回帰の弾き分けを十分に表せない。これらは参照から測った値に見せかけず、楽曲台本由来の創作目標として同じ生成要求へ統合する。

創作目標と参照目標の識別子、対象、観測条件が衝突する場合は、自然言語から都合よく優先順位を推測せず、生成前に失敗させる。統合済み目標と元入力のhashを保存し、後段で片方だけを再構築しない。

## モデルへ渡さない情報

実行記録には参照曲名、SMFのSHA-256、基準成果物のSHA-256、方式版を保存する。一方、モデルへ渡す匿名目標には次を含めない。

- 参照曲名と近傍曲名
- 参照SMFのhash
- コピーフィンガープリント
- 参照曲の生の音符列

モデルへ渡すのは、匿名化した意味目標、解決済み制御、固定品質、新規性条件である。

## 新規性と一般品質

参照232曲の完全一致コピーフィンガープリントは自動不合格とする。部分一致は診断として残すが、一般的な閾値はまだ固定しない。

一般品質は参照への近さと分け、少なくとも次を検査する。

- 構成木と参照関係が整合する。
- 上声と下声があり、伴奏が単調な同音量連打や常時同型へ退化しない。
- 宣言和声がある楽譜生成単位では伴奏が和声に従い、前景の和声外音に音楽上の理由がある。
- 低域で密集した第三音や不協和な間隔を避ける。
- 回帰は同じマテリアルと分かりながら、演奏または楽譜に差がある。
- 約180秒の演奏、長い終止、最終ペダル解放を持つ。
- MusicXMLとSMFを再読込みでき、元の下位表現と一致する。

一般品質への合格は、聴感上の作風類似や美的品質の証明ではない。

## 参照省略時の多様性

単一medoidだけを使うと生成初期値が偏るため、内部実験では、参照特徴を構築でき、コピー重複がなく、極端に孤立していない実在曲の集合からseed付きで一曲を選べる。候補集合、分析manifest、seed、選択結果のhashを実行前に固定し、望ましい結果が出るまでseedを変更しない。

この方式は多様な参照から完走できるかを検証するための内部入力である。公開要求で参照を省略したときの既定値を、自動的に変更しない。

## 未検証の範囲

- 匿名化した特徴目標だけで聴感上の作風類似を得られるか。
- 参照特徴の各目標が、複数の参照でどこまで到達可能か。
- 参照曲固有の長期構成を、拍情報へ依存せず安定して取り出せるか。
- 部分コピーを不合格にする一般的な閾値。

参照曲固有の長期構成は、安定した正解を得られていないため初版の生成目標へ含めない。固定校正曲v8は変換器と品質検査の回帰fixtureに限って使い、通常生成のマテリアル、構成、初期値として使わない。
