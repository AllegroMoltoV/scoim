# 高さ制御の解決設計

`高さ`は、参照232曲の平均MIDI音高のmin/maxを共通座標にした連続値である。単純移調を出発点にできるが、低くするほど第三音や第七音の密集を避け、根音、完全五度、オクターブを優先する。安全に到達できない要求は端点へ届いたと偽らず、到達範囲と未達量を返す。

| 項目 | 内容 |
|---|---|
| 文書の役割 | `高さ`の要求解決とv2変換方式の現在有効な設計の正本 |
| 設計版 | 0.6 |
| 最終更新日 | 2026-09-12 |
| 生成プロファイル | `solo_piano_3m_v1` |

この文書は[生成制御](generation-control-interface.md)のうち、高さ固有の要求解決、低音域再配置、到達不能時の扱いを所有する。

## 結論

参照232曲で定めた高さの共通座標と、個別の基準曲から安全に到達できる範囲は別である。v3は整数半音の全体移調を行い、下方向の候補だけで、低域の色付け音を近い根音または完全五度へ再配置する。品質に合格した全候補の実測値から、要求値、生目標、達成値、誤差、到達可能範囲を分けて返す。

利用者向けの明示的な`高さ=0`と、内部候補の`semitones=0`を混同しない。前者は参照232曲の最小値と最大値の算術中点である。後者は無移調候補であり、系譜識別子以外の音楽内容を変えない。上方向の候補も低域の問題を悪化させないため、一様移調だけを行う。

低音域では第三音、第七音、減五度をそのまま下げず、根音と完全五度を優先する。ノートを削除せず、発音位置と演奏指定を保つ。第三音が区間内からなくなり長短が曖昧になることは許容し、`あかるさ`の共変動として記録する。

到達不能な要求を、音域外ノートの切捨て、少数の極端音、終止だけの移動で攻略しない。到達不能なら通常SMFを返さず、安全端点を調査するときだけ診断専用成果物を作る。

単一基準曲で機械検証に合格しても、高さを公開Schemaへ追加しない。複数基準曲と知覚上の自然さを確認するまで、内部機能として扱う。非v8入力の内部縦断に一般品質を使っても、参照作風への適合や公開可能性を証明したとは扱わない。

## 入力と出力

入力は次のとおりである。

- `-1.0`から`1.0`までの高さ要求
- 参照232曲の高さ最小値と最大値
- 変換前のPiecePlan、ScoreSpec、PerformanceSpec
- ピアノ音域21〜108

解決結果は次を持つ。

- 要求正規化値
- コーパス上の生目標
- 選択した整数移調量
- 根音・完全五度へ再配置した音数
- 12半音単位で上へ移した音数
- 新規または悪化した異声部同音と局所交差の件数
- 実際の平均MIDI音高
- 実際の正規化値
- 生目標との差
- 安全に到達できる生値と正規化値の範囲
- `exact`、`quantized`、`unreachable`の状態
- 通常候補または診断専用成果物の区分

## 共通座標から生目標への変換

コーパス最小値を`minimum`、最大値を`maximum`、要求値を`requested`とし、生目標を次で求める。

```text
target = minimum + ((requested + 1) / 2) * (maximum - minimum)
```

要求値を範囲内へ切り詰めない。非有限値と範囲外値は変換前に拒否する。

## 候補列挙と選択

変換前の全ノートの最小・最大を求め、全ノートがMIDI 21〜108へ収まる整数半音を列挙する。各整数半音について全体移調を行う。負の整数半音だけ低音域再配置を行い、演奏へ展開して既存品質ゲートと高さ固有ゲートを実行する。

候補選択に使えるのは、次をすべて満たす候補だけである。

1. 変換後の全ノートがMIDI 21〜108に収まる。
2. `validate_pipeline`と、入力の役割に応じた既存品質ゲートに合格する。v8回帰では既存v8品質ゲート、非v8の内部縦断では一般品質ゲートを使う。
3. 低音域の色付け音、低音間隔、新規または悪化した声部衝突が0件である。
4. 変換後の平均MIDI音高が、参照232曲の最小値から最大値までに収まる。

合格候補のうち、生目標とRenderedPerformanceの実測平均との差が最小のものを選ぶ。同じ誤差なら、絶対移調量が小さい方を選ぶ。それでも同じなら、低い方を選ぶ。目標を越える近似を無条件に優先しない。合格候補の実測平均の最小値と最大値を、その基準曲の到達可能範囲とする。

非v8の内部縦断では、Pipeline、一般品質、候補SMFの再読込、発音頻度不変、高さ変換契約を全候補で検査してから選択する。いずれかに不合格の候補は、最近傍選択と到達可能範囲の両方から除く。最終候補を選んだ後だけ検査して、次善候補を失う実装にはしない。

状態は次のように決める。

| 状態 | 条件 |
|---|---|
| `exact` | 生目標との差が浮動小数点計算上0である |
| `quantized` | コーパス範囲内の最近傍であり、生目標との差が1半音以内である |
| `unreachable` | 安全な最近傍でも、生目標との差が1半音を越える |

1半音は音楽品質の許容幅ではなく、整数半音と決定的な再配置を使うv2方式の解像度である。実際の誤差を必ず保存する。

## 中間表現の変更範囲

全体移調量を`semitones`とする。

- 全ScoreNoteの`pitch`へ`semitones`を加える。
- PiecePlanの`tonal_center`へ`semitones`を加え、12の剰余を取る。
- 各PlanNodeの`harmonic_focus`が存在する場合、`semitones`を加え、12の剰余を取る。
- 全ScoreHarmonyの`root_pitch_class`へ`semitones`を加え、12の剰余を取る。
- PiecePlanとScoreSpecの識別子へ方式と移調量を含め、系譜を区別する。
- PerformanceSpecは変更しない。

構成、派生関係、和音品質、声部、相対時刻、音価、奏法、演奏タイミング、velocity、ペダルを変更しない。低音域再配置により一部の相対音程は変わるが、ノート数とevent_idは保つ。

### 低音域再配置

`harmonies`と`foreground_voice`を持つ楽譜生成単位の伴奏声部を対象にする。

低音域再配置は`semitones < 0`の候補だけへ適用する。`semitones=0`は元音高を保ち、`semitones>0`は全音高を一様に上げる。上方向移調は音程と声部間隔を変えず、低音域から遠ざかるため、変換前からある低域色付け音を別音へ置換しない。

1. MIDI 48未満にある根音と完全五度は候補として残す。
2. MIDI 48未満にある第三音、第七音、減五度は、その音と時間的に重なる全宣言和声で共通して使える根音または完全五度へ置き換える。
3. 置換候補はMIDI 21〜108から選び、全体移調後の音高との差が小さい順、同差なら低い順にする。
4. 異声部同音、局所交差、同一楽譜生成単位内の同音重複を新たに生む候補は除く。
5. MIDI 48未満で最低2音の間隔が7半音未満なら、根音、完全五度、その他の優先順を保ち、優先度の低い音を12半音単位で上へ移す。
6. 減三和音は完全五度を持たないため、減五度を低域へ残さず、根音だけを置換先にする。
7. 安全な置換先がない整数移調は不成立とする。根音または完全五度を省略せず、ノートを削除しない。

ScoreHarmonyのqualityは和声文脈を表し、全構成音を常時鳴らす義務ではない。低域の第三音を再配置した結果、区間内から第三音がなくなり長短が曖昧になることは許容する。これは和声破綻ではなく、`あかるさ`の共変動として測定する。

### 声部衝突の差分判定

変換前からある異声部同音を、新方式が作った衝突と混同しない。重なる上下声のイベントID対と`upper - lower`を変換前後で比較する。

- 変換前に`upper - lower > 0`だった組が、変換後に0以下となった場合は、新規衝突または新規交差として不合格にする。
- 変換前に`upper - lower = 0`だった組は、0のままなら既存衝突として許容し、負へ悪化した場合だけ不合格にする。
- 変換前に`upper - lower < 0`だった組は、値がさらに小さくなった場合だけ不合格にする。
- 正の音程差が縮まっても正のままなら、声部衝突ではないため不合格にしない。

### 和声宣言のない終止

`final-tonic`は、全体移調後にMIDI 48未満となる上声終止音を12半音単位で上へ移す。音高クラス、音数、event_id、時刻、音価を保ち、下声より上かつMIDI 48以上の開離配置にする。

`ending`は自動再配置しない。ピアノ音域、異声部同音、局所交差、低音間隔を検査し、不合格なら候補全体を不成立にする。

## 方式比較

2026-08-25の可否判定では、v8入力に対して全整数移調`-19`〜`+20`を比較した。

- 全体移調だけでは、低側は`-2`半音、実測平均62.56297420までしか低音域品質に合格しなかった。
- 色付け音を上のオクターブへ移す方式は、低側`-8`半音、実測平均56.59939302より下で声部衝突を避けられなかった。
- 衝突する色付け音を省略する方式は、`-19`半音、実測平均46.26442308まで下がったが、35音を削除して伴奏リズムと音数固定を変えた。
- 根音・完全五度へ置き換える方式は、`-19`半音、実測平均45.60546282まで、ノート削除なしで全候補の品質に合格した。

根音・完全五度への置換方式をv2に採用する。コーパス低端42.00496032との差3.60050250は残るため、`-1.0`を達成扱いにしない。より低い範囲が必要になった場合は、局所削除を後付けせず、高さ目標をScoreSpec生成前へ渡して声部と和声を共同設計する。

## 品質検査

高さの主効果は、平均、中央値、10・90パーセンタイル、上声平均、下声平均で確認する。低・中・高で各値が同方向へ動き、少数の極端音だけが主平均を動かしていないことを確認する。低音域再配置を含むため、すべてが同じ半音数だけ動くことは要求しない。

固定品質は、既存v8の検査を再利用する。終止和音の期待音高クラスはA minorへ固定せず、変換後の宣言主音とmodeから計算する。遷移、変奏、和声、非和声音、区分境界、テンポ、180秒、音数、ペダル、終止を高さ専用の規則へ複製しない。

`RenderedPerformance`を`ReferencePiece`へ決定的に投影し、4項目基準と同じ`extract_control_observables`で、あかるさ、重なり、発音頻度の共変動を記録する。共変動を0へ強制しない。第三音の再配置で長短が曖昧になり、あかるさが暗い寄りのニュートラルへ動くことを許容する。ノート数、発音位置、音価、PerformanceSpecは固定するため、発音頻度に差が出た場合は変換不具合として扱う。

## 到達不能と診断成果物

`unreachable`の要求には、通常候補用ディレクトリへSMFを書き出さない。安全な到達可能下端を確認する場合は、別の診断処理で`diagnostic_only`成果物として生成する。

通常候補と診断成果物は、JSONの状態、用途、ファイルパスを分ける。診断成果物を利用者要求の達成例、公開候補、匿名試聴の正答候補として扱わない。

内部縦断では、候補検査に使ったSMFを診断成果物として保持してよい。解決結果には`artifact_role`を保存し、`exact`または`quantized`だけを`normal_candidate`、`unreachable`を`diagnostic_only`とする。`unreachable`では安全端点のPiecePlan、ScoreSpec、PerformanceSpecと候補診断を保存しても、`outputs/final.mid`を作らず、成果物一覧にも通常SMFのパスを載せない。

全候補が品質、変換契約、SMF再読込み、発音頻度保持、またはコーパス範囲のいずれかで棄却された場合は、`unreachable`ではなく実行`failed`とする。各候補へ棄却理由を保存し、`candidates.json`、`result.json`、失敗manifestを確定する。安全端点が存在しないため、PiecePlan、ScoreSpec、PerformanceSpec、通常SMFを出力しない。失敗済みrunを不完全runとして暗黙に再実行しない。

## 実行系譜

方式版、入力DSL、コーパス基準、出力と合否を決める依存実装のSHA-256から決定的な`run-id`を作り、`.appendix/height-control-v2/runs/<run-id>/`へ保存する。異なる入力や実装は異なる実行先へ解決し、以前の候補を今回の成果物として上書きしない。スクリプトは今回の成果物の絶対パスを表示する。
