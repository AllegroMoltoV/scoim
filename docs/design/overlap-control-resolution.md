# 重なりの内部観測と既存対照

`重なり`は利用者向け制御ではなく、同時発音の薄さと参照作風を調べる内部観測である。主な値は、ペダルを除き、発音中ノート数を経過時間で重み付けした平均とする。既存の18候補は過去の対照を再現するために残すが、新しい公開パラメータへは接続しない。

## 結論

`重なり`のコーパス内位置は、参照232曲の時間加重平均ポリフォニーの最小値を`-1.0`、最大値を`1.0`とする。既存対照は、現在の基準曲から指定値へ近づけるため、ノートを追加または削除せず、既存音の音価と親区分のアーティキュレーションだけを変更する。

候補を実際に演奏へ変換し、主生値と品質を測ってから最も近い安全候補を選ぶ。要求値へ届かない場合は端点へ到達したと偽らず、要求値、目標生値、達成値、安全到達範囲、未達量を返す。この処理は既存実験の再現と内部診断に限る。

## 入力と出力

入力は、基準のPiecePlan、ScoreSpec、PerformanceSpec、参照基準v3、および`-1.0`から`1.0`の要求値である。参照基準v3のmanifestと成果物ハッシュを検証できない場合は実行しない。

出力は、次を含む解決結果と3段IRである。

- 要求正規化値と対応する目標生値
- 採用候補ID
- 達成生値と達成正規化値
- 安全候補の到達範囲
- 目標との差
- `exact`、`quantized`、`unreachable`の状態
- 品質、不変条件、変更した音符役割の診断

`exact`の許容誤差は生値で`1e-8`とする。安全候補であることと、要求値へ到達できたことは別に記録する。

## 音符役割

役割はevent_idの文字列規則に依存せず、[楽譜生成単位](glossary.md#楽譜生成単位)、ScoreNote、ScoreHarmonyから決定する。

1. `foreground_voice`と一致する声部を前景、それ以外を伴奏とする。
2. 発音時点を含むScoreHarmonyが一つだけある場合、音高を根音、完全五度、その他の和声音、和声外音へ分類する。
3. 同時に始まる伴奏音の最低音が根音または完全五度なら、低音支点とする。
4. `ending`、`final-tonic`、`transition-ab`、`transition-ba2`、テヌート、楽譜生成単位の終端まで届く音は保護する。

和声が一意に定まらない音と和声外音は初版の変更対象にしない。同じ音高でも局所和声と同時発音集合が異なれば役割が変わる。

## 候補変換

### 薄くする方向

変更可能な音価を1単位へ短縮する。次の順に累積適用する。

1. 伴奏の第三音、第七音などの和声音
2. 低音支点ではない伴奏の根音と完全五度
3. 前景の和声音

低音支点、保護音、和声外音は短縮しない。ノート数、発音位置、音高、声部、奏法、和声、構成、ペダルを保つ。

### 厚くする方向

現在の音価を短くせず、次の順に累積適用する。

1. 低音支点
2. その他の伴奏の根音と完全五度
3. 前景の和声音
4. 残りの伴奏和声音

伴奏音は、現在の和声区間の終端、楽譜生成単位の終端、同じ声部・同じ音高の次回発音のうち最も早い時点まで延長できる。前景音は、現在の和声区間の終端、楽譜生成単位の終端、同じ声部の次回発音のうち最も早い時点までとする。和声区間を越えず、同じ音高の再打鍵を覆わない。伴奏内で同じ声部の別音と重なることは、同一和声内のアルペジオを和音として保持する意図的な結果として許可する。

### 演奏指定

PerformanceSpecの親区分`a1`、`b`、`a2`だけを、`light`、`score`、`legato`のいずれかへ統一する候補を持つ。子区分の明示指定は変更せず、親から継承する区分だけへ作用させる。他の演奏指定、ペダル、時刻揺らぎ、強弱は保つ。

## 候補集合と選択

初版の候補集合は、事前到達性検査で測定した次の18個へ固定する。未測定の組合せを自動的に増やさない。

- 無変更1個
- 親区分のアーティキュレーションだけを`light`、`score`、`legato`へ変える3個
- 薄くする音価段階3個
- 厚くする音価段階4個
- 薄くする各段階と`light`の組合せ3個
- 厚くする各段階と`legato`の組合せ4個

品質と不変条件を通る候補を構造的な安全候補とする。そのうち参照コーパスの生値範囲内にあるものだけを解決候補にする。目標生値との差が最小の解決候補を選び、同値なら変更音符数、変更した親区分数、候補IDの順で決定する。これにより同じ入力は同じ候補へ解決される。

## 必須検査

- PiecePlan、ノート数、発音位置、音高、velocity、声部、奏法、ペダル、発音群数を保つ。
- 保護対象の楽譜生成単位と保護音を変更しない。
- 音価延長は和声区間を越えない。
- 既存のv8品質ゲートへ合格する。
- 薄い側、中間、厚い側の各成果物について、主生値とほかの3軸の共変動を保存する。
- 候補の安全性と要求到達状態を混同しない。

発音群数は30 ms群化で測る。この制御はnote-onを変更しないため、発音頻度を意図的に変えない。

## 既知の限界

初版は基準曲の既存ノートと和声を利用するため、元の楽譜にない新しい和音配置は作れない。時間加重平均ポリフォニーを動かせても、聴感上の「厚い」「薄い」が自然に成立する保証はない。人間試聴は他項目と最後にまとめ、合格するまで公開Schemaへ接続しない。
