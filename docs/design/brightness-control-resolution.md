# あかるさ制御の解決設計

`あかるさ`は、個々の和音を置き換える量ではなく、曲全体の主音、旋法、和声機能、遷移、終止を一貫させる調性計画として扱う。利用者入力は`-1`、`0`、`1`の3値であり、参照232曲のmin/maxを共通座標に使う。現在の方式は固定校正曲で機械検証済みだが、新曲生成と知覚上の合格は未確認である。

| 項目 | 内容 |
|---|---|
| 文書の役割 | `あかるさ`3値の要求解決と全曲調性計画の現在有効な設計の正本 |
| 設計版 | 0.3 |
| 最終更新日 | 2026-09-12 |
| 生成プロファイル | `solo_piano_3m_v1` |

この文書は[生成制御](generation-control-interface.md)のうち、あかるさ固有の調性計画、接続句、到達不能時の扱いを所有する。

## 結論

あかるさは、個々の短三和音を長三和音へ置き換える量ではなく、曲全体の主音、旋法、区分別の和声機能、接続句、終止を一貫させる調性計画として解決する。

固定v8は`-1`と`1`の二端点を扱う。参照232曲のあかるさ最小値を`-1`、最大値を`1`とする共通座標は維持するが、単一基準曲から安全に到達できる範囲とは分ける。要求値、参照生目標、達成生値、正規化達成値、未達量を返し、参照端点へ届かない候補を達成扱いにしない。

`0`は局所的な長短調混合や二端点の部分適用で作らない。主音相対Dorianを曲全体で一貫した中間調性計画として使う。固定v8診断では既存品質を保ち、正規化値`-0.33980714`で3入力値の中間帯へ入った。これは中間値の知覚合格や新曲生成での到達を証明しない。人間試聴は高さ、発音頻度と最後にまとめ、試聴完了まで公開Schemaへ接続しない。

## 入力と出力

入力は次のとおりである。

- 固定v8校正では、あかるさ要求`-1`、`0`、`1`
- 通常生成では、明示されたあかるさ要求`-1`、`0`、`1`と、選択した参照曲の匿名目標
- 参照232曲のあかるさ最小値と最大値
- 変換前のPiecePlan、ScoreSpec、PerformanceSpec
- ピアノ音域21〜108

解決結果は次を持つ。

- 要求値
- 参照コーパス上の生目標
- 適用した調性計画ID
- 共通座標の達成生値と正規化達成値
- 生目標との差と正規化未達量
- 宣言主音固定の`major_minor_profile_margin`と`modal_degree_balance`
- A1、B、A2の区分別あかるさ
- 高さ、重なり、発音頻度の共変動
- 修復したイベントID
- 接続句の和声、上声経路、経路変形コスト
- 品質ゲートと構造不変性の結果
- 入力、参照基準、移植元診断、出力SMFのSHA-256

## 通常生成へ渡す意味目標

通常生成では、固定v8のマテリアルIDや絶対和音列を再利用しない。明示された3値を`tonal_hierarchy`へ解決し、PiecePlan、和声、旋律の各段階へ同じ主音相対規則を渡す。

| 要求 | PiecePlanのmode | 曲全体の原理 | 終止 |
|---:|---|---|---|
| `-1` | `minor` | 短調の主音、前属、属、回帰を区分間で一貫させる | 短主和音 |
| `0` | `minor` | Dorian。短主和音、長III、長IV、短v、長VIIを主音相対で使う | 短主和音 |
| `1` | `major` | 長調の主音、前属、属、回帰を区分間で一貫させる | 長主和音 |

`0`でmajor区分とminor区分を交互に置く方式は使わない。statement、contrast、returnの各役割にDorianを短調端点と区別する長IVを少なくとも1件置く。release以外の和声はDorian音階内とし、releaseは短主和音にする。旋律は和声構成音だけへ固定せず、Dorian音階内の経過音と隣接音を許す。理由のない遠い和声外音は許さない。

参照曲から継承した連続あかるさ値は、3値のどれかへ丸めない。明示3値用の調性計画を適用せず、`unverified_continuous_reference`として従来の参照目標を維持する。

参照最小値と最大値の算術中点は生値`0.04238740`、正規化値`0`である。最初の内部到達判定では、3入力値の最近傍境界である正規化`-0.5`から`0.5`を中間帯とする。帯内でも達成値と0からの残差を保存する。帯外は`not_reached`とし、一般品質に合格してもあかるさ中間の肯定証拠や昇格候補にしない。

## 共通座標

参照232曲と生成SMFを、同じ`extract_control_observables`経路で測る。参照最小値を`minimum`、最大値を`maximum`、生値を`raw`とし、次で正規化する。

```text
normalized = 2 * (raw - minimum) / (maximum - minimum) - 1
```

生成候補の主音と旋法は、共通座標では参照曲と同じ方法で推定する。別の診断として、PiecePlanの宣言主音を固定した`major_minor_profile_margin`と`modal_degree_balance`も保存する。明るい候補は、共通座標と宣言主音固定記述子がどちらも暗い候補より高くなければ不合格とする。推定主音の切替だけで明るさが上がった候補を採用しない。

## 全曲調性計画

マテリアルIDの`a1-`と`a2-`は先頭区分名を外し、共通するAマテリアル役割として解決する。

### 暗い側

| マテリアル役割 | 4和音の進行 |
|---|---|
| `a-theme` | Am、Dm、F、E |
| `a-theme-prime` | Am、F、Dm、E |
| `a-contrast` | F、C、Dm、E |
| `a-contrast-prime` | F、Dm、C、E |
| `a-return` | Am、Dm、F、E |
| `a-return-prime` | Am、F、Dm、E |
| `b-theme` | C、F、Am、E |
| `b-theme-prime` | C、Dm、Am、E |
| `b-contrast` | F、C、G、E |
| `b-contrast-prime` | F、Dm、G、E |
| `b-return` | C、F、Am、E |
| `b-return-prime` | C、Dm、Am、E |

暗い側の`transition-ab`はC-Am、`transition-ba2`はiv-iv、すなわちDm-Dmとする。

### 明るい側

| マテリアル役割 | 4和音の進行 |
|---|---|
| `a-theme` | A、D、A、E |
| `a-theme-prime` | A、A、D、E |
| `a-contrast` | D、A、D、E |
| `a-contrast-prime` | D、D、A、E |
| `a-return` | A、D、A、E |
| `a-return-prime` | A、A、D、E |
| `b-theme` | A、D、E、A |
| `b-theme-prime` | A、E、D、A |
| `b-contrast` | D、A、E、A |
| `b-contrast-prime` | D、E、A、A |
| `b-return` | A、D、E、A |
| `b-return-prime` | A、E、D、A |

明るい側の`transition-ab`はI-IV、すなわちA-D、`transition-ba2`はIV-IV、すなわちD-Dとする。

### 和声と音高の写像

各ScoreHarmonyは、同じ開始位置と音価を保ったまま目標の根音と品質へ置き換える。元の和音構成音は、根音、第三音、第五音という役割を同じ添字の目標構成音へ写す。元の和声外音は、暗い側ではC sharp、F sharp、G sharpをC、F、Gへ、明るい側ではC、F、GをC sharp、F sharp、G sharpへ写し、近い同音名位置を選ぶ。

変換後は、元から経過音または隣接音だった前景音について、前後音に対する接近方向、離脱方向、1半音または2半音の間隔を保てる場合だけ役割を復元する。それでも残った理由のない前景和声外音は、同時点の宣言和声音のうち元音高に最も近い音へ移す。同差なら低い音を選ぶ。接続句はこの修復対象にせず、経路探索だけで成立させる。

PerformanceSpec、発音位置、音価、音符数、event_id、声部、奏法は変更しない。PiecePlanのmodeは端点に合わせる。明るい側ではharmonic_focusがある全ノードをAへ合わせる。

## 接続句の経路探索

接続句の上声6発音を、各時点の宣言和声音から決定的に選ぶ。候補音高はMIDI 21〜108を全列挙する。

制約は次のとおりである。

1. 直前区分から接続句先頭まで2半音以内とする。
2. 接続句内部の隣接跳躍を5半音以内とする。
3. 接続句末尾から次区分先頭まで2半音以内とする。
4. 接続句内部と前後境界で、隣接発音位置の同音再打鍵を禁止する。音価が重ならない同音も禁止する。
5. 同音重複、宣言和声外音、新規または悪化した異声部同音と声部交差を作らない。

経路変形コストは、各候補音と元音高の差の絶対値、および候補の隣接音程と元の隣接音程との差の絶対値の総和とする。最小コストを選び、同点では音高列の辞書順で決める。安全経路がなければ、個別イベントや前後主題を修復せず、その調性計画を不成立とする。

## 品質条件

二端点は、次をすべて満たす場合だけ機械合格とする。

- `validate_pipeline`と既存v8品質ゲートに合格する。
- 和声を持つ全楽譜生成単位の伴奏和声音率が1.0、低音間隔違反が0、未解決前景和声外音が0である。
- 変換前と比べて、新規または悪化した異声部同音と声部交差が0件である。
- 構成、マテリアル系譜、発音位置、音価、音符数、声部、奏法、PerformanceSpecが候補間で一致する。
- 共通座標と宣言主音固定記述子が同じ明暗方向を示す。
- A1、B、A2の各区分で、明るい候補が暗い候補より高い生値を持つ。
- 180秒、終止、ペダル、区分速度、変奏、接続句の既存条件を保つ。

## 到達可能範囲

固定v8入力と参照基準v3で確認した値は次のとおりである。

| 端点 | 共通座標生値 | 正規化達成値 | 参照端点との差 |
|---|---:|---:|---:|
| 暗い側 | -0.35283035 | -0.98592434 | 最小値より0.00564237高い |
| 中間Dorian | -0.09382773 | -0.33980714 | 算術中点より0.13621513低い |
| 明るい側 | 0.38398258 | 0.85215556 | 最大値より0.05926494低い |

この範囲はあかるさ一般の限界ではなく、固定v8入力と現方式で機械確認できた安全範囲である。`-1`または`1`の要求に対して達成値が端点へ届かなければ、状態を未達として返す。安全上端を参照最大値へ再定義しない。

移植元診断の固定v8 SMF SHA-256は、暗い側`8edfc58e1f06a65054f16365d665d3e364956391d8a44ab9db143ca5744b7128`、明るい側`04fec227f64efc21c566e562b12978807d4c79318d5cc697f7acb1fd4dc107f1`である。中間診断の証跡は`.appendix/brightness-middle-mode-feasibility-v1`に保存する。製品実装は固定v8二端点のハッシュと生値へ一致しなければならない。

## 未解決事項

- 明るい側の未達量を小さくする別調性計画が必要か。
- Dorian中間が新曲でも中間帯へ入り、聴感上も自然な中間として成立するか。
- 複数の基準曲でも3値の同じ方式が成立するか。
- 公開Schemaへ追加できるか。

これらを解決するまで、3値は内部校正機能とする。
