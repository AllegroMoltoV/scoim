# 生成制御インターフェース

[生成プロファイル](glossary.md#生成プロファイル)`solo_piano_3m_v1`では、参照曲と、`あかるさ`、`高さ`、`発音頻度`の最大3項目で生成結果を制御する。3項目は完全に独立しているとは仮定せず、主に変えたい性質と一緒に変わった性質を分けて報告する。名称と測り方は決めているが、生成対照に合格した項目だけを公開するため、現時点の公開Schemaではまだ受理しない。

## 目標とする要求

```json
{
  "schema_version": 1,
  "profile": "solo_piano_3m_v1",
  "reference": "WhiteCurtain.mid",
  "controls": {
    "あかるさ": 0,
    "高さ": 0.0,
    "発音頻度": 0.0
  }
}
```

`reference`と各制御値は省略できる。参照曲を指定して制御を省略した場合は、その参照曲自身の正規化値を使う。値を明示的に`0`とした場合は、参照232曲の実測最小値と最大値の算術中点を使う。省略と`0`を同じ意味にしない。

会話、JSON、CLIは同じ正規要求へ集約する。CLIへ個別のフラグを多数追加せず、要求ファイルを一つ渡す。

## 参照曲の省略

参照を省略した場合の公開既定値は、検証済み特徴空間の実在曲medoidを使う。現在の基準は`SonataForHouseMoving.mid`である。各軸の中央値を組み合わせた実在しない仮想曲を既定値にはしない。

多様な初期値を調べる内部実験では、検証済みの代表的な領域からseed付きで別の参照曲を選べる。この内部選択は、公開要求の意味や既定参照を黙って変えない。

## 共通座標

各項目は、参照232曲で観測した主値の最小値を`-1`、最大値を`1`へ線形に写す。これはコーパス内の位置であり、値が高いほど曲の品質が高いという意味ではない。生成要求が安全に到達できない場合は、要求値、目標値、安全に到達できる端点、未達量を分けて返す。

曲ごとに、生値、正規化値、分布診断、測定方式の版を保存する。外れ値一曲が端点を決める問題は診断するが、観測後に都合よくmin/maxを変更しない。

## `あかるさ`

`あかるさ`は整数の`-1`、`0`、`1`だけを受け付ける。

| 値 | 意味 |
|---:|---|
| `-1` | 暗い調性計画 |
| `0` | 中間の調性計画 |
| `1` | 明るい調性計画 |

主な観測値は、曲全体の長調プロファイル相関から短調プロファイル相関を引いた値とする。ただし、個々の短三和音を長三和音へ置き換えるだけ、全体を移調するだけ、modeラベルだけを書き換えるだけでは達成としない。主音、旋法、区分ごとの調性階層、和声機能、開始、遷移、終止まで一貫した計画として変える。

長調の中に短三和音が含まれることや、低域の濁りを避けて第三音を省くことは許容する。高さ、同時発音の厚さ、発音頻度の自然な共変動も許容するが、それらだけで明るさの差が生じた候補は合格にしない。詳しい生成規則は[あかるさ制御](brightness-control-resolution.md)に置く。

## `高さ`

`高さ`は`-1.0`から`1.0`の連続値で、使われるMIDI音高の中心を表す。全note-onの平均音高を主値とし、中央値、10・90パーセンタイル、上声と下声の平均を併記する。少数の極端音だけで平均を動かした候補は合格にしない。

全体移調は禁止しないが、低くするほどボイシングを疎にする。MIDI 48未満では第三音や第七音を密集させず、根音、完全五度、オクターブを優先する。長短調が曖昧になった場合は、`あかるさ`が暗い側の中立へ動く共変動として記録する。詳しくは[高さ制御](height-control-resolution.md)に置く。

## `発音頻度`

`発音頻度`は`-1.0`から`1.0`の連続値で、1秒間に新しい発音のまとまりが何回始まるかを表す。30 ms以内に始まる複数音は、一つの和音またはまとまりとして1回に数える。

未所属の最初のnote-onを群の基準時刻とし、その時刻から30 ms以内を同じ群へ含める。連鎖結合はしないため、0、20、40 msのnote-onは2群になる。主値は`発音群数 / 演奏秒数`とし、発音間隔、休止、音価の分布を併記する。

全体BPMだけを変える、同じ音を機械的に細かく連打する、和音の音数だけを増やす方法は合格にしない。生成時は3分間の整数発音群予算へ解決し、演奏後にSMFから再測定する。詳しくは[発音頻度制御](attack-frequency-control-resolution.md)に置く。

## 内部観測の`重なり`

`重なり`は利用者向け制御ではない。発音中のノート数を経過時間で重み付けした平均として測り、参照作風と同時発音の薄さを診断する。匿名試聴で制御差を識別できなかったため、公開パラメータから外した。

ノート数、発音群サイズ、低音域の間隔と併せて記録する。値を上げるための不協和音追加や、値を下げるための単旋律化を品質改善としない。既存実験の再現条件は[重なりの内部観測](overlap-control-resolution.md)に置く。

## 主効果と共変動

| 操作 | 主に変える対象 | 一緒に記録するもの |
|---|---|---|
| `あかるさ` | 全曲の調性階層、旋法、和声機能 | 高さ、重なり、発音頻度、velocity、場面差 |
| `高さ` | 音高の平均、中央値、分布 | あかるさ、重なり、発音頻度、声部交差 |
| `発音頻度` | 1秒当たりの発音群数 | あかるさ、高さ、重なり、音価、休止 |

単独制御の検証は、3項目の完全な独立性を証明するためではない。何が主に変わり、何が副作用として変わったかを説明できるようにする。二つの項目が複数の参照でほぼ同じ変化しか生まない場合は、不自然に直交化せず、統合または片方の非公開を検討する。

## 公開条件

各項目を一つずつ次の順で確認する。

1. 参照232曲の観測値とmin/maxを固定する。
2. 同じ参照と同じ上流成果物から、要求値だけを変えた対照を作る。
3. 主な観測値が要求方向へ動くことを確かめる。
4. 別の観測値、固定品質、極端な単純化や過密化を調べる。
5. 主観名を持つ項目は、少数の匿名試聴で意味を校正する。

主効果が識別できない、別の印象が主効果を上回る、共変動だけで差を説明できる、極端解へ退化する場合は公開しない。3項目すべての完成を初版の前提にはしない。

## 結果表示

結果は単一の総合点にせず、固定条件の合否、各制御の要求値、解決目標、観測結果、到達不能量、主な共変動、内部の`重なり`、未検証範囲、生成物のpathを分けて示す。状態は達成、未達、未検証、適用外を区別する。
