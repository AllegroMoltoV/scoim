# 局所的な終止感の匿名比較

## 評価の目的

この評価では、曲の末尾付近で音楽が区切れたように感じられるかを比較します。曲全体の構成、好み、音質、演奏技術は採点しません。回答は、後続の Claude Sonnet 4.6 判定器へ与える例と、人間判断との未提示照合に使います。

## 評価対象

評価対象は `.appendix/closure-calibration/listen/` 配下の `pair-01` から `pair-16` です。各フォルダーには `sample-A.mid` と `sample-B.mid` があります。各組は同じ参照曲から切り出した同程度の長さの抜粋です。片方が実際の終盤、もう片方が曲中の自然な区切りですが、どちらかは明かしません。

## 回答方法

各組の A と B を同じ再生環境で聴いてください。必要なら何度聴いてもかまいません。音楽がその位置で終わったと感じる方を選びます。使える回答は `A`、`B`、`同程度`、`判定不能` のいずれかです。

`.appendix/closure-calibration/evaluation-form.json` の各 `answer` へ回答を記入してください。理由を残す場合は、同じ項目の `reason` に一文で記入できます。`selection-manifest.json` には正解役割が記録されているため、回答を終えるまで開かないでください。

## 回答後の扱い

16 組は回答前に few-shot 用 8 組と未提示検証用 8 組へ固定されています。回答後も分割を変更しません。次の段階では Claude Sonnet 4.6 へ A/B 順と B/A 順を別々に提示し、両方が人間判断と一致するかを測ります。未提示検証に不合格なら、LLM 判定を生成の loss、順位、合否へ使いません。
