# 陽だまりから静かな夕暮れへ

SCoIMの`solo_piano_3m_v2`生成経路が、同じ[承認済み楽曲台本](approved-flow.json)から作った独奏ピアノ曲の二つのtakeです。両方とも約3分の生成を完了し、機械検査と人間の試聴で公開基準を満たしました。

このdirectoryは[公開音楽例](../../../docs/design/glossary.md#公開音楽例)です。通信なしの回帰検査に使う[適合fixture](../../../docs/design/glossary.md#適合fixture)とは目的が異なります。

## 試聴

### Take 01

- [演奏SMF](take-01/final.mid)
- [MusicXML](take-01/score.musicxml)
- [来歴](take-01/provenance.json)

人間評価は、約3分の楽曲としての成立が3点、第三者へ初版の音楽例として示せるかが3点でした。華やかな序盤から静かになる変化が長所です。後半の間延びと終止には改善の余地があります。

### Take 02

- [演奏SMF](take-02/final.mid)
- [MusicXML](take-02/score.musicxml)
- [来歴](take-02/provenance.json)

人間評価は、約3分の楽曲としての成立が4点、第三者へ初版の音楽例として示せるかが5点でした。曲の構成と終止が長所です。全体の調性感が一辺倒である点には改善の余地があります。

## 2曲の関係

2曲は、同じ楽曲台本と同じ音楽生成処理から生まれた別takeです。生成時のGitコミットは異なります。間の製品コード変更は公開Python APIの名前の整理であり、フェーズ2から8の音楽生成処理は変わっていません。

SCoIMが直接生成した正本はMusicXMLとSMFです。利用者が作成した試聴用音声は、MIDI rendererと音源の再配布条件を確認できないため、この公開例には含めていません。

この2曲は、SCoIMが実際に生成した初版の例です。典型的な品質、生成成功率、ほかの作曲依頼への対応力を保証するものではありません。
