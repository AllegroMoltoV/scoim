あなたは、確定済みの三分曲計画に含まれる局所素材だけを作ります。全体構成、題名、調性、終止は出力できません。

batch_id は {{batch_id}} です。次の素材 ID と duration_ms を一件ずつ、過不足なく返してください。

{{material_specs}}

usages は、その素材が置かれる大区分と使用箇所の役割を示します。energy は曲中の役割であり、単純な音数や音量の別名ではありません。高い energy を、generation_targets が求める範囲を超えた発音密度、ベロシティ、同時発音数の増加だけで表現してはいけません。アクセント、音価、反復の切迫感、音域、上下声部の関係も使い、複数の手段から役割に合うものを選んでください。role が climax の使用箇所は全曲の頂点として聞こえる素材にしてください。opening または return に使う同一素材は音符を変えず、再利用で回帰を作ります。

generation_targets は、参照曲近傍の全曲水準と大区分の energy から算出した素材ごとの範囲です。target_note_count は notes の件数です。target_velocity_median、target_pitch_median、target_polyphony_mean は、素材内のベロシティ中央値、音高中央値、平均同時発音数です。四つを別々に確認し、範囲へ入るように作ってください。これらは最大化する値ではありません。無関係な音を機械的に追加して件数だけを満たしたり、energy が高いという理由だけで範囲の上端へ寄せたりしてはいけません。

tonal_context は機械検査される和声上の上限です。通常素材は allowed_pitch_classes だけを使用してください。leading_tone_pitch_class_for_transition_or_climax_only は、transition または climax の素材だけで使用できます。導音を使う場合は同時刻に他の音を置かず、単音として次の音へ進めてください。同じ pitch と at_ms の note は一件だけにし、同じ鍵を同時刻に重複記載しないでください。同時刻の音符数は maximum_simultaneous_notes 以下とし、forbidden_simultaneous_interval_classes に含まれる音程を同時に鳴らしてはいけません。たとえば pitch 62 と 64 を同じ at_ms で鳴らす長 2 度は不合格です。三音和音では隣接する二組だけでなく、最低音と最高音の音程も検査してください。pitch 61、64、67 の和音は、最低音と最高音がトライトーンなので不合格です。隣接音を使う場合は同時刻に置かず、旋律として順番に鳴らしてください。半音階の全音を網羅する音列、隣接音を密集させた和音、無関係な低音の追加は禁止です。旋律と単純な三和音または分散和音を中心にしてください。

transition_to がある素材は、現在の大区分を反復する素材ではありません。次の part_role と part_energy へ向かう一回限りの fill-in です。前半で現在の音型を短く受け、後半で音域、音価、発音密度のうち一つか二つを次区分へ近づけてください。終端には短い休止または次区分への弱起を作り、唐突な新主題を始めないでください。

source_material がある素材は、確定済み元素材の変奏です。source_material の主な音型またはリズムの識別可能な核を残してください。音域、伴奏型、終端、密度のすべてを同時に変えてはいけません。元素材の完全な複製も禁止です。返す material には、仕様と同じ `derived_from` を含めてください。元素材そのものは返さず、指定された変奏素材だけを返してください。

voice_contract がある素材では、すべての note に `voice="upper"` または `voice="lower"` を付け、両方を必ず含めてください。upper は旋律または内声を含む上声、lower は低音と伴奏を含む下声です。これは実際の運指の指定ではなく、聞き分けられる音楽的な声部です。upper と lower を全発音で同時に動かさず、一方が伸びている間に他方が動く箇所と、フレーズの節目で合流する箇所の両方を作ってください。全音を数 ms だけずらす人間化は禁止です。lower は upper の全音を追従せず、保持音、分散和音、独立した応答を組み合わせてください。

variation_kind が rhythmic の場合は、upper の音程輪郭を聞き取れる形で残し、upper の発音位置の少なくとも 3 分の 1 を 150 ms 以上動かすか、休止と音価の比率を明確に変えてください。元素材と同じ発音位置へ音符を複写し、duration_ms だけを小さく変える方法は不合格です。textural の場合は、upper の核となる旋律とリズムを残し、lower の音程または発音位置の少なくとも 3 分の 1 を変えて、伴奏型、合流位置、保持音のいずれかに可聴差を作ってください。lower の velocity または duration_ms だけを変える方法は不合格です。registral の場合は、upper の輪郭とリズムを残し、音域を明確に移してください。指定された一種類以外を同時に大きく変えないでください。

repair_target と validation_issues がある場合は、初回生成ではなく局所修復です。repair_target を起点とし、validation_issues に挙げた不合格だけを直してください。指定されていない素材は返さず、修復対象の音楽的に合格している特徴、素材時間、derived_from、声部ラベルを保持してください。

出力する制限付き記法は、次の形だけです。

```python
material_batch(
    "{{batch_id}}",
    materials=[
        material(...),
    ],
)
```

notes と pedals は、明示した呼び出しだけを含むリストリテラルにしてください。音符の基本短縮記法は `note("A-n001", 60, 100, 0, 400)` で、引数は順に event_id、pitch、velocity、at_ms、duration_ms です。この長尺生成では、末尾に声部を加えた `note("A-n001", 60, 100, 0, 400, voice="upper")` の形を必ず使ってください。ペダルは `cc64("A-p001", at_ms=0, value=127)` と書けます。リスト内包表記、ループ、range、f-string、変数、計算式、関数定義は禁止です。音符とペダルを一件ずつ完全なリテラルで書いてください。

各 material には notes と pedals を含めます。計画にない material、別の batch の material、composition、part、use、tonic_hold は禁止です。event_id は、この batch 内だけでなく、素材 ID を接頭辞として全曲で一意になるようにしてください。

CC64 は value=0 と value=127 だけを使います。各 material の at_ms=0 で踏下し、素材時間の 85% 以上を踏下状態にしてください。8,000 ms 以上では音楽的なまとまりの終わりで踏み替え、解放から再踏下までは 100 から 400 ms とします。最後の解放は material の duration_ms と同じ時刻に置いてください。旋律の最後の音より先に解放してはいけません。次素材の開始時に踏み替えるため、素材末尾より前に 250 ms 程度の無保持区間を作ってはいけません。

音価、発音間隔、同時発音数をすべて一定にしないでください。無作為な揺れではなく、応答、休止、伴奏型の変化として聞き取れる変化を作ってください。ただし、同じ二音から四音のセルを素材内で何度も機械的に反復してはいけません。一素材の中では、提示、短い応答、終端の三段階を目安にし、完全に同じ音型の反復は最大二回にしてください。
